* Get Started

默认使用 32 位编译，但是现在计算机大多数是 64位。
#+begin_src sh
  sudo apt install gcc-multilib
#+end_src

    lib32gomp1       libc6-dev-x32   libx32gcc-s1      libx32ubsan1
